Tenho também interesse em aprender **React Native** para expandir meus conhecimentos para o desenvolvimento de aplicações mobile.

🚀 **Meu objetivo é continuar aprendendo, construir projetos cada vez melhores e evoluir constantemente como profissional da área de tecnologia.**
